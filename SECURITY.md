# Security Policy

## Supported version

Security fixes apply to the latest version on the main branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email **Engr.philipokeke@gmail.com** with the affected component, reproduction steps, impact, and suggested mitigation.

You can expect an acknowledgement within five business days. Please allow reasonable time for investigation and remediation before public disclosure.

## Browser automation safety

Never commit login credentials, session cookies, personal screenshots, private URLs, or production data. Use environment variables and sanitized test fixtures. Reports involving unsafe WebDriver configuration, dependency vulnerabilities, or exposed artifacts are especially helpful.
